# Git Lessons

Репозиторий создан в ходе прохождения курса **Git и GitHub для начинающих**.

## Что изучено в курсе:
* Базовые команды (`git init`, `git add`, `git commit`)
* Алиасы и логирование (`git log`)
* Работа с ветками (`git branch`, `git checkout`)
* **Разрешение конфликтов слияния** (`Merge Conflicts`)
* Синхронизация с GitHub (`git push`, `git pull`)
